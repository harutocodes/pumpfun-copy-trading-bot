# pumpfun-copy-trading-bot

Landing page for PumpCopy, a pump.fun copy trading bot for Windows.
Plain HTML and CSS, served by GitHub Pages:
https://harutocodes.github.io/pumpfun-copy-trading-bot/

The bot itself (source, releases, per-tab setup guide) lives in
[harutocodes/pumpfun-terminal](https://github.com/harutocodes/pumpfun-terminal).
The pump.fun SDK it builds on is
[Solgrid.Pumpfun](https://github.com/solgrid-development/Solgrid.Pumpfun).

Local preview:

    python -m http.server 8080

or just open index.html in a browser.
